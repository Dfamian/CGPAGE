# Fotos del carrusel

Coloca aquí las fotografías cuadradas que aparecerán en el primer bloque de la página. No necesitas registrarlas manualmente: el carrusel las detecta y las muestra automáticamente.

Formatos admitidos: AVIF, GIF, JPEG, JPG, PNG y WebP. Si los archivos tienen nombres como `foto-1.jpg`, `foto-2.jpg` y `foto-3.jpg`, aparecerán en ese orden.
