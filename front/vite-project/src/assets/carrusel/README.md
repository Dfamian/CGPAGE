# Fotos del carrusel

Coloca aquí las fotografías que aparecerán en el primer bloque de la página. No necesitas registrarlas manualmente: el carrusel las detecta y las muestra automáticamente. Se conserva la proporción de cada imagen; no tienen que ser cuadradas.

Formatos admitidos: AVIF, GIF, JPEG, JPG, PNG y WebP. Si los archivos tienen nombres como `foto-1.jpg`, `foto-2.jpg` y `foto-3.jpg`, aparecerán en ese orden. Selecciona una foto para verla completa; puedes cerrar la vista con la X, Escape o haciendo clic fuera de ella.
